# Mini Projeto - Análise de Dados com Python

## Objetivo

Realizar uma Análise Exploratória de Dados (AED) utilizando a base de varejo, aplicando técnicas de limpeza, estatística descritiva, agrupamentos e visualização de dados com Python.

---

## Tecnologias utilizadas

- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## Estrutura do projeto

dados/
    Varejo.csv

output/
    compras_genero.png
    top10_categorias.png
    df_limpo.csv

Miniprojeto_Cristiane_Analise_de_Dados_T4.py

README.md
.gitignore

---

## Como executar

1. Clone o repositório.

2. Instale as bibliotecas:

pip install pandas numpy matplotlib seaborn

3. Execute:

python Miniprojeto_Cristiane_Analise_de_Dados_T4.py

---

## Resultados

O projeto realiza:

- Importação da base
- Limpeza dos dados
- Tratamento de duplicatas
- Conversão de datas
- Estatística descritiva
- Agrupamentos
- Visualizações gráficas
- Exportação da base limpa
